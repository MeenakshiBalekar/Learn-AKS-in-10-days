# Learn AKS in 10 Days

A hands-on learning journey to build strong Azure Kubernetes Service (AKS) fundamentals through practical labs, architecture diagrams, notes and sample deployments.

## Goal
Understand AKS step by step through 10 days covering:

- AKS Fundamentals
- Kubernetes Objects
- Ingress and Networking
- Scaling and Autoscaling
- Security
- Observability
- CI/CD
- Resilience
- Reference Architectures

## Learning Approach
Each day includes:

- Concept Overview
- Hands-on Lab
- Architecture Diagram
- YAML Samples
- Notes and Key Takeaways

## 10-Day Roadmap

| Day | Topic |
|-----|------|
| Day 1 | AKS Cluster Fundamentals |
| Day 2 | Pods, Deployments and Services |
| Day 3 | Ingress and Load Balancing |
| Day 4 | Scaling in AKS |
| Day 5 | AKS Security Basics |
| Day 6 | Monitoring and Observability |
| Day 7 | AKS Networking |
| Day 8 | CI/CD to AKS |
| Day 9 | Resilience and High Availability |
| Day 10 | Production Reference Architecture |
